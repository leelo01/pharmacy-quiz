Which Pharmacy Subject Are You? 💊

A fun, interactive quiz that helps pharmacy students discover which pharmacy subject best matches their personality traits.

🌐 Take the Quiz

Try the live quiz
📖 About the Project
Have you ever wondered which pharmacy subject matches your personality? This quiz turns that question into a lighthearted, interactive experience.

Participants answer a series of questions about their personal traits and receive a pharmacy-subject result. The project was created for fun and to encourage students to explore pharmacy subjects in a more engaging way.
✨ Features
- Interactive, question-based quiz
- Pharmacy-subject results based on the user's answers
- Progress bar and quiz navigation
- Subject-related images
- Responsive, styled user interface
🧪 Subjects Featured
The repository includes images for the following subjects:
- Analytical
- IBS
- Organic
- Orientation and Legislation
- Pharmaceutics
- Pharmacognosy
- Pharmacy
🛠️ Built With
- HTML — page structure
- CSS — layout, styling, navigation, and progress-bar presentation
- JavaScript — quiz interactions and result tracking

2. Open the downloaded pharmacy-quiz folder.
3. Open index.html in your browser.
